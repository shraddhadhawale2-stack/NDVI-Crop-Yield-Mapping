NDVI-Based Crop Yield Prediction and Mapping Using Machine Learning¶

Project Objective¶

The main objective of this project is to develop a Machine Learning Regression model for predicting crop yield using NDVI (Normalized Difference Vegetation Index) along with important agricultural and environmental factors.

The project aims to analyze how vegetation health, rainfall, soil moisture, temperature, irrigation, and crop characteristics affect crop yield.

Problem Statement & Objectives¶

Problem Statement

Accurate crop-yield estimation is important for farmers, agricultural planners, and decision-makers. Traditional yield estimation methods can be time-consuming and may not effectively capture variations in crop health and environmental conditions.

This project uses NDVI and agricultural data to build a regression model that can predict crop yield more efficiently.

Objectives To analyze crop and environmental data. To study the relationship between NDVI and crop yield. To preprocess and prepare the dataset for Machine Learning. To train a regression model for crop-yield prediction. To evaluate the model using MAE, MSE, RMSE, and R² Score. To understand the important factors affecting crop yield.

Why is this project important?¶

NDVI provides useful information about vegetation health and crop growth. Combining NDVI with rainfall, soil moisture, temperature, irrigation, and other agricultural factors can help estimate crop yield.

Project Setup & Data Collection¶

The project is developed using Python and Machine Learning libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

The dataset contains information related to crop type, region, season, NDVI, rainfall, temperature, soil moisture, irrigation, soil properties, and crop yield.

The target variable used for prediction is:

Feature Preprocessing¶

In [16]:
preprocessor = ColumnTransformer(
    transformers=[
        (
            "num",
            Pipeline([
                ("imputer", SimpleImputer(strategy="median")),
                ("scaler", StandardScaler())
            ]),
            numerical_cols
        ),
        (
            "cat",
            Pipeline([
                ("imputer", SimpleImputer(strategy="most_frequent")),
                ("encoder", OneHotEncoder(handle_unknown="ignore"))
            ]),
            categorical_cols
        )
    ]
)

Model Building¶

A Random Forest Regression model is used for crop-yield prediction.

Random Forest can capture non-linear relationships between NDVI, environmental conditions, soil properties, irrigation, and crop characteristics.

In [17]:
from sklearn.ensemble import RandomForestRegressor

model = Pipeline([
    ("preprocessor", preprocessor),
    (
        "regressor",
        RandomForestRegressor(
            n_estimators=250,
            random_state=42,
            n_jobs=-1
        )
    )
])

model.fit(X_train, y_train)

print("Model Training Completed Successfully!")
